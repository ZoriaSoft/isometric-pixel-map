## Body (copy-paste)

```
I built a small free tool: paint retro isometric pixel maps entirely in the browser.

Inspired by the recent wave of isometric “pixel city” exploration pages — but this one is writeable: you open the link, paint a mini world, and export PNG or JSON. No account, no install.

What works today:
- 32×32 classic 2:1 isometric grid
- Ground + props layers, pen / erase / fill / undo-redo
- Built-in pixel palette (grass, water, houses, trees…)
- Demo village seed so you don’t start on a blank page
- Export PNG (shareable) + JSON (reloadable)
- Touch: one-finger paint, two-finger pan + pinch

Stack: Godot 4.6 → Web (gl_compatibility), static host.

Link: https://zo.pub/triangle/isometric-pixel-map
Source (MIT): https://github.com/ZoriaSoft/isometric-pixel-map

Would love feedback on UX (especially mobile) and which tiles people want next.
```

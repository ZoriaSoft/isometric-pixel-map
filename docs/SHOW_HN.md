## Body (copy-paste)

```
I built a small free tool: paint retro isometric pixel maps entirely in the browser.

Inspired by the recent wave of isometric “pixel city” exploration pages — but this one is writeable: you open the link, paint a mini world, and export PNG or JSON. No account, no install.

What works today:
- 32×32 to 64×64 isometric grid (pick the size)
- Ground + props layers, pen / erase / fill / undo-redo, brush sizes
- Built-in pixel palette (grass, water, houses, trees…) + tile variants so large maps don't look tiled
- Upload your own tile PNG and paint with it
- 6 job templates (settlement, wilderness, crossroads, coast, stronghold…)
- Export PNG (shareable) + JSON (reloadable)
- Share a map as a URL — compressed, fits any browser
- Touch: one-finger paint, two-finger pan + pinch

Stack: Godot 4.6 → Web (gl_compatibility), static host, installable as PWA.

Link: https://zo.pub/triangle/isometric-pixel-map/index.html
Source (MIT): https://github.com/ZoriaSoft/isometric-pixel-map

Would love feedback on UX (especially mobile) and which tiles people want next.
```
